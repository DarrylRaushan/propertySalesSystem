# Executive pulse verification

The four top metric cards now act as one shared interaction surface. Clicking Expected sales opened the Executive pulse dialog containing expected sales, total leads, priority leads, and active properties together. Clicking Active properties opened the identical all-four-signals dialog, confirming that the metric cards do not create separate deep-dives.

The deep-dive presents four animated microtrend cards and a unified management readout that connects value, demand, urgency, and inventory in one decision frame. The default dashboard remains the same height because the full comparison appears only in the on-demand dialog.

At the 375px mobile breakpoint, the metric strip remains a two-column grid with persistent “Open shared pulse” affordances. The Executive pulse content is configured to stack its signal cards and management readout items into one column on narrow displays, preserving scanability without introducing extra default-page scroll.
